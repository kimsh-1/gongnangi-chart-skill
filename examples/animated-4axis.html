컨텍스트 엔지니어링의 4축 — 정보를 관리하는 프레임워크
Lance Martin, 2025-06-23
01
Write
윈도우 밖에 저장
필요 없는 정보를 외부에 저장하되, 필요할 때 자동 로드
CLAUDE.md에 규칙 저장 → 매 세션 자동 로드. Memory Tool 적용 → +39% 향상
→
02
Select
필요한 조각만
전체를 넣지 말고, 지금 이 스텝에 필요한 것만 골라서 로드
파일 50개 전체 로드 (X) → grep으로 함수 하나만 추출 (O). 도구 RAG → 정확도 3배
→
03
Compress
토큰을 줄인다
같은 의미를 더 적은 토큰으로. 도구 출력을 요약으로 대체
1200줄 파일 → 한 줄 요약. 60-80% 절감, 품질 손실 5% 미만
→
04
Isolate
컨텍스트 분리
하나의 거대한 컨텍스트 대신, 여러 개의 격리된 컨텍스트로
서브에이전트 = 독립 컨텍스트. 컨텍스트 격리 → 리서치 +90%
